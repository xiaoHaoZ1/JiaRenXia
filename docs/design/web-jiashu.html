家里的事，留在家里

家人的名字、关系、生日和电话，是一个家最私密的东西。所以从一开始，家人侠就只把它们留在你的手机里。

阅读隐私政策
  • 不上传

    家人档案、关系和提醒只存在你的手机里，家人侠不会把它们上传到任何服务器。

  • 不用注册

    不用注册、不用登录，默认也不需要联网。

  • 没有后台

    家人侠没有账号和服务器，你的资料没有任何地方可以上传。
