# 演示版 2.4.1-demo 发布记录（2026-11-07）

为实拍「碰一碰结为夫妻」做的双机演示包，同时顺手把官网测试版从 2.3.0-debug 更新到 2.4.1-debug。

## 包信息

- worktree `worktrees/demo-build` / 分支 `feature/demo-build`，基线 main `7d4df32`（测试版 2.4.1）
- 新 buildType `demo`：`initWith(debug)`，`applicationIdSuffix=".demo"`、`versionNameSuffix="-demo"`、debug 签名 → `com.jiarenxia.app.demo` / vc59 / `2.4.1-demo`，与正式版、测试版三包共存
- `BuildConfig.DEMO_ROLE`（`-PdemoRole=groom|bride`，缺省 groom）决定首启预装哪份家谱；`BuildConfig.TAP_AID` 演示版为 `F04A52580002`（正式/测试版仍是 `F04A52580001`，apduservice 在 `src/demo/res/xml/`）——避免与红米上的正式版抢 HCE 路由，碰一碰只能在演示版之间进行
- 两份预装数据在 `app/src/demo/assets/`（由 `DemoFamilyBackupTest -PtestFamily=true` 生成到 `testdata/` 再复制，密码 `test1234`）：
  - `demo_groom_zhudi.jrxb`：MingFamily 去掉妻族与儿女孙辈，朱棣 + 35 位家人
  - `demo_bride_xu.jrxb`：徐皇后 + 8 位家人（徐达、谢氏、徐辉祖、徐增寿、徐氏、徐妙锦、徐钦、徐景昌），两数据集无同名人物，合并无待确认项
- `data/demo/DemoSeed.kt`：库为空时启动路由前导入对应资产并置已看引导；「我的」页仅演示版有「重置演示数据」（清空 + 重导 + 回家庭页，外观设置保留），演示版隐藏测试工具组
