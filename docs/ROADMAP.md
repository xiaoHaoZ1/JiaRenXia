## 待办功能

### 兄弟姐妹排行（siblingRank）

**状态：设计草案待评审（2026-10-26 讨论）。**

动机：只知道"第几个孩子"而不知道生日时（如伯祖父的几个儿子），关系图应能按排行排序；目前成对长幼（relativeAgeOrder）只能两两表达，录入繁琐。

草案要点：

- `Person.siblingRank: Int?`，"在兄弟姐妹中排第几，1=最长"；不分男女，只排序。
- 同组同胞两两比较的排序信号优先级：**完整生日 > 成对 SIBLING/COUSIN 长幼记录 > 排行 > 共同参照人传递推断 > 兜底（姓名拼音/id）**；组内名次取约束拓扑序。
- 消费方：关系图（GraphFamilyPlacement / GraphFamilyLayout，长者居左、幼者居右）、家庭页"子女"分组排序、详情页展示。
- 影响面：`:core:model` Person + `PersonEntity` 新列 + MIGRATION_15_16 + schemas 导出；PersonDraft、编辑/详情页；BackupJson（可选键，向后兼容）；FamilySnapshot/FamilyMerge 冲突键。
- 待定决策：① 字段挂人物还是亲子关系上（草案倾向人物）；② 排行与成对记录冲突时谁优先（草案：记录 > 排行）；③ 录入控件（数字输入 / 中文"老大老二"选择器）；④ 首期范围（编辑页+关系图 / 含详情页展示、子女列表、添加子女快捷项）。
- 不做：称谓引擎不读排行；填排行不级联生成 SIBLING 记录。
